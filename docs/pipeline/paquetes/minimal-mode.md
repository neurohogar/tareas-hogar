# Package: minimal-mode

First feature of epic E6 of `docs/v3/plan.md` («Días de baja capacidad y regreso sin deuda»): each task can be marked «esencial» in the panel, and a «Modo mínimo» that the user turns on by hand (from a ⋮ menu in the header of Pendientes) leaves only the essential tasks in view; the non-essential recurring ones stay paused (they do not become overdue and come back without debt) and the non-essential one-off ones are hidden. The block rescheduling of E6 is left for another feature.

## Specs

- **S1** (§4.1): «| `essential` | boolean | no | Essential task (see **Essential**, below). Any kind of task. Without the field, it is not essential. |»
- **S2** (§4.1): «**Essential**: any task, one-off or recurring in any mode, can be marked essential (`essential` = `true`). It is the mark that the minimal mode (§5.8) uses to decide which tasks stay in view. A task saved without the field is not essential (there is no migration); unchecking the mark removes the field. A new task starts not essential with the minimal mode off and essential with it on (§6.2). The mark is never invalid. It does not change the status (§5) or the order of the list, and it does not change when the task is completed, postponed, paused, resumed or changes kind or mode.»
- **S3** (§5.8): «Only **recurring** tasks can be paused. A task can be paused in two independent ways: **by hand** (`pausada`, with **Pausar**) and **by the minimal mode** (below). In the rest of the spec, «paused» without more words means paused by either cause.»
- **S4** (§5.8): «**Minimal mode** («Modo mínimo»): a mode that the user turns on and off by hand (§6.1) to leave only the essential tasks (§4.1) in view on a bad day, without the rest piling up as overdue.»
- **S5** (§5.8): «- **State**: the mode is on or off. It stays on until the user turns it off from the same menu: the app never turns it on or off by itself (no timer, no end date) and it survives reloading the app. It can be turned on with no essential task. The state is a single value synced between devices (§7), not a field of a task.»
- **S6** (§5.8): «- **Paused by the minimal mode**: while the mode is on, every recurring task that is **not essential** is paused by the mode. It behaves like a paused task (the **Paused** bullet above: no status, it does not become overdue, disabled checkbox, no row in **Pendientes**) and does not depend on `pausada`: a task paused by the mode and by hand is paused by both. The mode never writes `pausada` and never undoes it: a task paused by hand stays paused, with the mode on or off, until **Reanudar** (essential ones too: with the mode on they stay paused and out of view, §6.1).»
- **S7** (§5.8): «- **One-off tasks**: they are never paused (only recurring tasks can be). While the mode is on, a **non-essential one-off task** is **hidden** (§6.1): its status, date and «Tocaba …» do not change, and when the mode is turned off it comes back exactly as it was.»
- **S8** (§5.8): «- **Essential tasks**: the mode changes nothing of them: status, order, texts, steps, minimal version, postponement, checkbox and actions follow the rest of the spec as with the mode off.»
- **S9** (§5.8): «- **Turning it off** is a **Reanudar** (above) of every recurring task that is not essential and is not paused by hand, with `reanudadaEn` = the moment of turning it off. Each one comes back as if newly created at that moment, even one completed the day before the mode was turned on: interval tasks (relative) are all `pending` at once; calendar tasks are `pending` if today is one of their days and `waiting` otherwise (§5.8, Resume). What happened during the mode does not count as overdue and no «Tocaba …» of the mode is shown. The moment of turning it on is the moment from which they stop being in view. Example: a relative task of every 2 days, last completed `2026-07-10T09:00:00`, not essential; the mode is turned on at `2026-07-14T08:00:00` and off at `2026-07-20T10:00:00`: it was out of view in between, and at `2026-07-20T10:00:00` it is `pending` (not «Tocaba hace 4 días»), with `reanudadaEn` = `2026-07-20T10:00:00`.»
- **S10** (§5.8): «- **Changing the mark with the mode on**: unchecking **Esencial** on an essential recurring task pauses it by the mode from the moment of saving (it leaves the list) and hides an essential one-off task. Checking **Esencial** on a non-essential task brings it back right away: a recurring one like turning the mode off for that task, that is, a **Reanudar** at the moment of saving (`reanudadaEn` = now), unless it is also paused by hand, in which case it stays paused (and without `reanudadaEn`); a one-off task as it was. Changing the kind with the mode on follows the same: a non-essential recurring task that becomes one-off is hidden (and resumed as the **Changing a paused recurring task to one-off** bullet says), and a non-essential one-off task that becomes recurring is paused by the mode. Marking essential is the only way back during the mode.»
- **S11** (§5.8): «- **Manual pause with the mode on**: a non-essential recurring task cannot be paused by hand while the mode is on (it has no **Pausar**, §6.2). A non-essential one that was already paused by hand stays so; **Reanudar** removes the manual pause and the task stays paused by the mode until the mode is turned off or it is marked essential. When the mode is turned off, a task still paused by hand stays paused.»
- **S12** (§5.8): «- **New task with the mode on**: it starts essential (§6.2); if it is saved unchecked, it is non-essential and the rules above apply from the moment of saving.»
- **S13** (§5.8): «- **No summary**: turning the mode on or off shows no summary, count or message of how many tasks were paused or came back, and no congratulations.»
- **S14** (§5.9): «- A paused task (§5.8) cannot be postponed, whether it is paused by hand or by the minimal mode. A postponed non-essential task keeps its `pospuesta` while it is paused by the mode or hidden; it expires by itself as above and has no effect while the task is out of view.»
- **S15** (§6.1): «- **Menu and minimal mode**: the header of **Pendientes** has a small **⋮** button, with the accessible name «Menú», that opens a menu with a single item, **Modo mínimo**, which shows whether the mode is on (a check mark when on). Tapping the item acts at that moment, without confirmation: it turns the mode on or off (§5.8) and closes the menu. The menu has no other items; "Completadas" and "Pausadas" stay where they are. While the mode is on, above the list there is a line with the text «Modo mínimo» in secondary text, without color, icon or counter. It is only text (tapping it does nothing) and it is shown even if the list is empty (with the mode on and no essential task, the list is empty with that line). Turning the mode on or off does not show any other message (§5.8).»
- **S16** (§6.1): «- **Which rows are in view with the mode on**: only the essential tasks (§4.1), in the same order and with the same rows as with the mode off. The non-essential ones, recurring (paused by the mode) and one-off (hidden), are in no way in view: neither with **Mostrar completadas** nor with **Mostrar pausadas**. A task paused by hand that is essential stays paused and is shown only with **Mostrar pausadas**; a non-essential one paused by hand is not shown even with it. The **Historial** (§6.3) does not change.»
- **S17** (§6.1): «- **Mostrar pausadas**: a check next to "Completadas", with the text "Pausadas". Off (the initial value), the paused tasks (§5.8) are not shown. With the mode on, it shows only the tasks paused by hand that are essential (the ones paused by the mode are never shown, above). On, they go at the end of the list (after the completed ones, if those are shown), by title in the alphabetical order above; each row dimmed, with the text "Pausada" instead of the overdue or return text and the checkbox disabled. The value is saved on that device, like "Mostrar completadas".»
- **S18** (§6.1): «- If the task is essential (§4.1), a small outlined star right after the title, on the same line, with the mode on or off and in every kind of row (pending, overdue, waiting, completed, paused). It has no color of its own (the color of the title text), the accessible name «Esencial» and no action: tapping it is tapping the row. It does not change the status or the order.»
- **S19** (§6.2): «- **Esencial**: a check with the text «Esencial» in the **Tarea** section, after the note (text only, no icon). It is saved with **Guardar** like any field and counts for **Unsaved changes**. On edit, it starts with the current value. On create, it starts unchecked with the minimal mode off and checked with it on (the mode as of the moment the panel opens); that starting value is the one the form is measured against, so it does not count as a change, and unchecking it does. If the mode changes with the panel open (for example from another device), the check is not changed. Enter in a one-line field also saves it.»
- **S20** (§6.2): «- **Pause / Resume** (only when editing a recurring task): a **Pausar** button; if the task is paused, the panel indicates it ("Pausada") and the button is **Reanudar**. With the minimal mode on this is different for a non-essential recurring task (**Minimal mode in the panel**, below). The button acts at that moment (saves and closes the panel), without going through **Guardar**; with unsaved changes, it first opens the action notice of **Unsaved changes**.»
- **S21** (§6.2): «| Non-essential recurring, not paused by hand | «Pausada por el modo mínimo» | no **Posponer**, **Quitar posponer**, **Pausar** or **Reanudar**; **Borrar tarea** stays |»
- **S22** (§6.2): «| Non-essential recurring, paused by hand | «Pausada» | **Reanudar** (it removes the manual pause; the task then stays paused by the mode and the panel shows the row above); no **Posponer**; **Borrar tarea** |»
- **S23** (§6.2): «The panel of a non-essential task is opened from the **Historial** (§6.3), the only way to reach it during the mode. Marking it **Esencial** and saving brings it back (§5.8). With the mode off, the panel is the usual one.»
- **S24** (§6.2): «- **Tarea**: at the top, "Pausada" or «Pausada por el modo mínimo» (if applicable), "Pospuesta hasta HH:MM" (or "hasta mañana HH:MM") and **Última vez**; then the title with the emoji beside it (the emoji button next to the Título field, with **Quitar emoji** below); the first step and the more steps; the minimal version; the note; the **Esencial** check.»
- **S25** (§6.6): «- **What it waits for with a session**: the response of Auth and the **first response** of tasks, of completions and of the state of the minimal mode (§7) (from the local cache or from the network), and also the **Atkinson Hyperlegible Next** font and **Noto Color Emoji**, even if they have to be downloaded. It goes away when all that is ready, with a **minimum of 0.5 seconds** even if everything is ready right away.»
- **S26** (§7): «- `users/{uid}/settings/minimalMode`: the state of the minimal mode (§5.8), `{ active: boolean }`. Without the document, the mode is off.»
- **S27** (§7): «- **Minimal mode**: the state is user data synced between devices, not a local preference (§5.8): turning it on on one device turns it on on the others, and all agree on which tasks are paused and which are overdue. The unit of conflict is `active`: with two devices offline, the last change wins. Turning it off writes `active` = `false` and the `reanudadaEn` of the tasks it brings back (§5.8) in a single `writeBatch`, with the moment of turning it off as "now".»

## Decisions

- D1 (2026-11-22, user, the problem): «Sí, me pasa» (translation: «Yes, it happens to me»), to «¿Te pasa que hay días o semanas en que casi no podés hacer nada de la casa, y al volver la lista acumulada de atrasadas te agobia?» (translation: «Does it happen to you that there are days or weeks when you can barely do anything around the house, and when you come back the accumulated list of overdue tasks overwhelms you?»).
- D2 (2026-11-22, user, scope): «Modo mínimo» (translation: «Minimal mode»), described as «Marcás algunas tareas como «esenciales» en un momento tranquilo; en un día malo encendés el modo a mano y solo quedan esas a la vista, el resto pausado. Actúa antes de que se acumule.» (translation: «You mark some tasks as «essential» at a calm moment; on a bad day you turn the mode on by hand and only those stay in view, the rest paused. It acts before things pile up.»). The block rescheduling of E6 is another feature.
- D3 (2026-11-22, user, non-essential tasks): «Quedan en pausa» (translation: «They stay paused»), described as «Funcionan como la pausa de hoy: no se atrasan. Al apagar el modo vuelven como si arrancaran de nuevo, sin «Tocaba hace 2 semanas». Es el «regreso sin deuda». Solo las periódicas se pueden pausar.» (translation: «They work like today's pause: they do not become overdue. When the mode is turned off they come back as if they were starting anew, without «Tocaba hace 2 semanas». It is the «return without debt». Only recurring tasks can be paused.»).
- D4 (2026-11-22, user, one-off tasks): «Pueden ser esenciales y nada más» (translation: «They can be essential, and that is all»), described as «En el modo se ven solo las esenciales, puntuales incluidas; las puntuales no esenciales se esconden igual que en la primera opción.» (translation: «In the mode only the essential ones are seen, one-off included; the non-essential one-off ones are hidden just as in the first option.»), where the first option was «No se ven mientras dura el modo; al apagarlo vuelven tal cual estaban, con su fecha y su «Tocaba …» si ya pasó.» (translation: «They are not seen while the mode lasts; when it is turned off they come back exactly as they were, with their date and their «Tocaba …» if it already passed.»).
- D5 (2026-11-22, user, where it is switched): «En un menú o ajustes» (translation: «In a menu or settings»), then «Botón de menú en Pendientes» (translation: «Menu button in Pendientes»), described as «Un botón chico (⋮) en la cabecera de Pendientes que abre un menú con «Modo mínimo». No suma pestañas y queda a un toque, sin estar delante.» (translation: «A small button (⋮) in the header of Pendientes that opens a menu with «Modo mínimo». It adds no tabs and is one tap away, without being in front.»).
- D6 (2026-11-22, user, signal that it is on): «Una línea discreta» (translation: «A discreet line»), described as «Arriba de la lista, «Modo mínimo» en texto secundario, sin color ni contador.» (translation: «Above the list, «Modo mínimo» in secondary text, without color or counter.»).
- D7 (2026-11-22, user, essential mark in the row): «Sí, un indicador chico» (translation: «Yes, a small indicator»), described as «Un ícono o texto discreto en la fila para ver de un vistazo cuáles son esenciales y revisarlas en calma.» (translation: «A discreet icon or text in the row to see at a glance which ones are essential and review them calmly.»).
- D8 (2026-11-22, analyst, which tasks can be essential): any task, one-off or recurring in any mode, can be marked essential. A task saved without the mark is not essential (there is no migration). A new task starts not essential with the mode off and essential with the mode on (D25, D33). Because D4 includes one-off tasks and every new field of §4.1 is optional and "without the field" means "without a value". Reconciled with D25.
- D9 (2026-11-22, analyst, how long the mode lasts): the mode stays on until the user turns it off from the same menu; the app never turns it on or off by itself (no timer, no end date), and it survives reloading the app. Because the plan forbids "that the app turns the mode on or infers the state of the person" and the pause already lasts "until I resume it" (D1 of `pause`).
- D10 (2026-11-22, analyst, essential tasks with the mode on): the mode does not change anything of an essential task: its status, order, texts («Tocaba …», «Vuelve …»), steps, minimal version, postponement, checkbox, panel actions (Pausar, Reanudar, Posponer) and a manual pause follow §5, §6.1 and §6.2 as with the mode off; an essential task paused by hand stays paused and is shown only with **Mostrar pausadas** (D22, D24). Because the mode only takes the rest out of view (D2). Reconciled with D22 and D24.
- D11 (2026-11-22, analyst, non-essential one-off tasks): while the mode is on they are not shown in Pendientes, neither with **Mostrar completadas** nor with **Mostrar pausadas**; their status is not changed: when the mode is turned off they come back with their date and their «Tocaba …» if it already passed. Because it is the user's answer (D4) and «Pausadas» shows nothing the mode put aside (D24). Reconciled with D24.
- D12 (2026-11-22, analyst, changing the mark with the mode on): unmarking an essential recurring task with the mode on pauses it by the mode from that moment (it leaves the list), and an essential one-off one is hidden; marking a non-essential task as essential with the mode on (from its panel, opened from the **Historial**, D14) brings it back right away: a recurring one as on turning the mode off, that is, like **Reanudar** at the moment of saving (D21), unless it is also paused by hand, in which case it stays paused (D22); a one-off one as it was. Changing the kind with the mode on follows the same: a non-essential recurring task that becomes one-off is hidden (and is resumed as §5.8 says for that change), and a non-essential one-off task that becomes recurring is paused by the mode. Because the mode is defined by the mark: what is in view is always "the essential ones", whatever the moment the mark changed, and marking essential is the only way back during the mode (D23). Reconciled with D21-D23.
- D13 (2026-11-22, analyst, postponement): a postponed non-essential task keeps its `pospuesta` while it is paused by the mode or hidden; it expires by itself (§5.9) and has no effect while the task is out of view. Because §5.9: completing, undoing or editing do not delete it, it expires by itself.
