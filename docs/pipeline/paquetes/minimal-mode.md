# Package: minimal-mode

First feature of epic E6 of `docs/v3/plan.md` («Días de baja capacidad y regreso sin deuda»): each task can be marked «esencial» in the panel, and a «Modo mínimo» that the user turns on by hand (from a ⋮ menu in the header of Pendientes) leaves only the essential tasks in view; the non-essential recurring ones stay paused (they do not become overdue and come back without debt) and the non-essential one-off ones are hidden. The block rescheduling of E6 is left for another feature.

## Specs

## Decisions

- D1 (2026-11-22, user, the problem): «Sí, me pasa» (translation: «Yes, it happens to me»), to «¿Te pasa que hay días o semanas en que casi no podés hacer nada de la casa, y al volver la lista acumulada de atrasadas te agobia?» (translation: «Does it happen to you that there are days or weeks when you can barely do anything around the house, and when you come back the accumulated list of overdue tasks overwhelms you?»).
- D2 (2026-11-22, user, scope): «Modo mínimo» (translation: «Minimal mode»), described as «Marcás algunas tareas como «esenciales» en un momento tranquilo; en un día malo encendés el modo a mano y solo quedan esas a la vista, el resto pausado. Actúa antes de que se acumule.» (translation: «You mark some tasks as «essential» at a calm moment; on a bad day you turn the mode on by hand and only those stay in view, the rest paused. It acts before things pile up.»). The block rescheduling of E6 is another feature.
- D3 (2026-11-22, user, non-essential tasks): «Quedan en pausa» (translation: «They stay paused»), described as «Funcionan como la pausa de hoy: no se atrasan. Al apagar el modo vuelven como si arrancaran de nuevo, sin «Tocaba hace 2 semanas». Es el «regreso sin deuda». Solo las periódicas se pueden pausar.» (translation: «They work like today's pause: they do not become overdue. When the mode is turned off they come back as if they were starting anew, without «Tocaba hace 2 semanas». It is the «return without debt». Only recurring tasks can be paused.»).
- D4 (2026-11-22, user, one-off tasks): «Pueden ser esenciales y nada más» (translation: «They can be essential, and that is all»), described as «En el modo se ven solo las esenciales, puntuales incluidas; las puntuales no esenciales se esconden igual que en la primera opción.» (translation: «In the mode only the essential ones are seen, one-off included; the non-essential one-off ones are hidden just as in the first option.»), where the first option was «No se ven mientras dura el modo; al apagarlo vuelven tal cual estaban, con su fecha y su «Tocaba …» si ya pasó.» (translation: «They are not seen while the mode lasts; when it is turned off they come back exactly as they were, with their date and their «Tocaba …» if it already passed.»).
- D5 (2026-11-22, user, where it is switched): «En un menú o ajustes» (translation: «In a menu or settings»), then «Botón de menú en Pendientes» (translation: «Menu button in Pendientes»), described as «Un botón chico (⋮) en la cabecera de Pendientes que abre un menú con «Modo mínimo». No suma pestañas y queda a un toque, sin estar delante.» (translation: «A small button (⋮) in the header of Pendientes that opens a menu with «Modo mínimo». It adds no tabs and is one tap away, without being in front.»).
- D6 (2026-11-22, user, signal that it is on): «Una línea discreta» (translation: «A discreet line»), described as «Arriba de la lista, «Modo mínimo» en texto secundario, sin color ni contador.» (translation: «Above the list, «Modo mínimo» in secondary text, without color or counter.»).
- D7 (2026-11-22, user, essential mark in the row): «Sí, un indicador chico» (translation: «Yes, a small indicator»), described as «Un ícono o texto discreto en la fila para ver de un vistazo cuáles son esenciales y revisarlas en calma.» (translation: «A discreet icon or text in the row to see at a glance which ones are essential and review them calmly.»).
- D8 (2026-11-22, analyst, which tasks can be essential): any task, one-off or recurring in any mode, can be marked essential. A task saved without the mark is not essential (there is no migration). A new task starts not essential with the mode off and essential with the mode on (D25, D33). Because D4 includes one-off tasks and every new field of §4.1 is optional and "without the field" means "without a value". Reconciled with D25.
- D9 (2026-11-22, analyst, how long the mode lasts): the mode stays on until the user turns it off from the same menu; the app never turns it on or off by itself (no timer, no end date), and it survives reloading the app. Because the plan forbids "that the app turns the mode on or infers the state of the person" and the pause already lasts "until I resume it" (D1 of `pause`).
- D10 (2026-11-22, analyst, essential tasks with the mode on): the mode does not change anything of an essential task: its status, order, texts («Tocaba …», «Vuelve …»), steps, minimal version, postponement, checkbox, panel actions (Pausar, Reanudar, Posponer) and a manual pause follow §5, §6.1 and §6.2 as with the mode off; an essential task paused by hand stays paused and is shown only with **Mostrar pausadas** (D22, D24). Because the mode only takes the rest out of view (D2). Reconciled with D22 and D24.
- D11 (2026-11-22, analyst, non-essential one-off tasks): while the mode is on they are not shown in Pendientes, neither with **Mostrar completadas** nor with **Mostrar pausadas**; their status is not changed: when the mode is turned off they come back with their date and their «Tocaba …» if it already passed. Because it is the user's answer (D4) and «Pausadas» shows nothing the mode put aside (D24). Reconciled with D24.
- D12 (2026-11-22, analyst, changing the mark with the mode on): unmarking an essential recurring task with the mode on pauses it by the mode from that moment (it leaves the list), and an essential one-off one is hidden; marking a non-essential task as essential with the mode on (from its panel, opened from the **Historial**, D14) brings it back right away: a recurring one as on turning the mode off, that is, like **Reanudar** at the moment of saving (D21), unless it is also paused by hand, in which case it stays paused (D22); a one-off one as it was. Changing the kind with the mode on follows the same: a non-essential recurring task that becomes one-off is hidden (and is resumed as §5.8 says for that change), and a non-essential one-off task that becomes recurring is paused by the mode. Because the mode is defined by the mark: what is in view is always "the essential ones", whatever the moment the mark changed, and marking essential is the only way back during the mode (D23). Reconciled with D21-D23.
- D13 (2026-11-22, analyst, postponement): a postponed non-essential task keeps its `pospuesta` while it is paused by the mode or hidden; it expires by itself (§5.9) and has no effect while the task is out of view. Because §5.9: completing, undoing or editing do not delete it, it expires by itself.
- D14 (2026-11-22, analyst, Historial): the mode does not change the **Historial**: it shows all the completions, also those of non-essential tasks, and tapping one opens its panel as always. Completions can still be deleted. Because the mode is about Pendientes and §5.8 already allows deleting completions of a paused task.
- D15 (2026-11-22, analyst, the menu): the ⋮ menu has a single item, «Modo mínimo», which shows whether it is on and acts at the moment of tapping it (it turns the mode on or off and closes the menu). The menu has no other items: «Completadas» and «Pausadas» stay where they are. Because the user asked for a menu only to host the switch (D5) and moving the other checks is not part of the request.
- D16 (2026-11-22, analyst, the line «Modo mínimo»): it is only text, not a control (tapping it does nothing), and it is shown only while the mode is on; it is shown even if the list is empty. Because the user asked for a discreet signal without color or counter (D6) and the switch lives in the menu (D5).
- D17 (2026-11-22, analyst, the indicator in the row): the icon of D30 is shown on every essential task row, with the mode on or off, and in every kind of row (pending, overdue, waiting, completed, paused); it does not change the status or the order. Because the user wants to see which ones are essential at a glance (D7), and one rule for every row is simpler than hiding it when, with the mode on, every row is essential (D24 leaves only essential rows in view). Reconciled with D24 and D28.
- D18 (2026-11-22, analyst, sync of the mark): the essential mark is an independent field of the task in §7: the last change wins, per field, and an edit writes it only if it changed. Because it is the conflict rule of every field of §4.1.
- D19 (2026-11-22, analyst, no summary): turning the mode on or off shows no summary, count or message of how many tasks were paused or came back, and no congratulations. Because the plan's "Evitar" forbids «un resumen de «lo acumulado» al salir» and the signal is only the discreet line (D6).
- D20 (2026-11-22, user, P1 sync): «Sí, sincronizado» (translation: «Yes, synced»), described as «Encenderlo en el teléfono lo enciende también en la compu. Los dos dispositivos coinciden en qué tareas están pausadas y cuáles atrasadas.» (translation: «Turning it on in the phone also turns it on in the computer. Both devices agree on which tasks are paused and which are overdue.»).
- D21 (2026-11-22, user, P2 return): «Como Reanudar hoy» (translation: «Like Reanudar today»), described as «Cada una como si se creara en ese momento. Todas las de intervalo quedan pendientes de golpe, aunque la hayas hecho el día antes del modo. Las de calendario quedan pendientes si hoy es uno de sus días; si no, en espera.» (translation: «Each one as if newly created at that moment. Every interval task becomes pending at once, even one done the day before the mode. Calendar tasks are pending if today is one of their days, otherwise waiting.»).
- D22 (2026-11-22, user, P3 manual pause): «Sigue pausada» (translation: «It stays paused»), described as «Solo Reanudar la reanuda; el modo nunca deshace una pausa a mano. Las esenciales pausadas a mano también siguen pausadas, y fuera de la vista, durante el modo.» (translation: «Only Reanudar resumes it; the mode never undoes a manual pause. Essential tasks paused by hand also stay paused, and out of view, during the mode.»).
- D23 (2026-11-22, user, P4 panel): «Pausada por el modo mínimo» (translation: «Paused by the minimal mode»), described as «Sin Pausar ni Reanudar; para traerla de vuelta, marcarla esencial. Una sola salida, y el modo no se mezcla con las pausas a mano.» (translation: «With no Pausar or Reanudar; to bring it back, mark it essential. A single way out, and the mode does not mix with manual pauses.»).
- D24 (2026-11-22, user, P5 «Pausadas» with the mode on): «Solo las pausadas a mano» (translation: «Only the ones paused by hand»), described as «Nada de lo que dejó de lado el modo. Durante el modo no hay forma de ver las no esenciales en Pendientes.» (translation: «Nothing the mode put aside. During the mode there is no way to see the non-essential tasks in Pendientes.»).
- D25 (2026-11-22, user, P6 new task with the mode on): «Arranca esencial» (translation: «It starts essential»), described as «Queda a la vista: lo que creás en un día malo es lo que hace falta ahora; se puede desmarcar.» (translation: «It stays in view: what is created on a bad day is what is needed now; it can be unmarked.»).

Una forma válida de «pausar la casa» entera.» (translation: «The list stays empty with the «Modo mínimo» line. A valid way to "pause the house" entirely.»).

One tap on the bad day, but turning it on and off by accident wipes the debt of the non-essential tasks (as P2 decides).»).
- D30 (2026-11-22, analyst, which icon): a small star, outlined, next to the title (after the emoji and title, on the same line), without its own color (the color of the title text), with the accessible name «Esencial». It is not tappable apart from the row: tapping it is tapping the row. The **Esencial** check of the panel carries no icon (§6.2, Icons: checks are text only). Because the user accepted the star as the example (D28), a filled or colored star would read as a rating or an alarm, and an icon without visible text needs an accessible name (§6.2, Icons).
- D31 (2026-11-22, analyst, panel with the mode on): for a non-essential recurring task that the mode pauses, the panel shows «Pausada por el modo mínimo» where «Pausada» goes (top of **Tarea**, §6.2 Panel presentation) and **Acciones** offers neither **Pausar**, **Reanudar** nor **Posponer** (a paused task cannot be postponed, §5.9); **Borrar tarea** stays. A non-essential one-off task (hidden) has its panel as always. Because it is D23 and the position of «Pausada» already exists.
- D32 (2026-11-22, analyst, non-essential task paused by hand, with the mode on): it is out of view, also with **Mostrar pausadas** (D24). Its panel shows «Pausada» and **Reanudar**, because the manual pause is still its own (D22, D23: the mode does not mix with manual pauses); tapping **Reanudar** removes the manual pause, and the task then stays paused by the mode (panel as in D31) until the mode is turned off or it is marked essential. A non-essential recurring task cannot be paused by hand while the mode is on (D23: no **Pausar**). When the mode is turned off, a task still paused by hand stays paused (D22). Because the two pauses are independent and the user wants the mode never to undo a manual pause.
- D33 (2026-11-22, analyst, new task with the mode on): the **Esencial** check of the create panel comes checked if the mode is on at the moment the panel opens, and that value is the starting point of the form: it does not count as a change for **Unsaved changes** (§6.2: "the form is still as it was opened"), and unchecking it does. If the mode changes (for example from another device) with the panel open, the check is not changed. Because it is D25 and **Unsaved changes** is measured against the values when the panel was opened.
- D34 (2026-11-22, analyst, the mode state across devices): turning the mode on or off is a single synced value (D20), not a task field and not a local preference; with two devices offline, the last change wins (§7). The moment of turning it off is the "now" of the **Reanudar** of every non-essential recurring task it brings back (D21), and the moment of turning it on is when they stop being in view. The data of the mode lives under the user like the rest (§7, Security rules). Because D20 asks that both devices agree, and §7 resolves conflicts by last change.
- D35 (2026-11-22, analyst, changes for the spec-writer): textual rules of the spec that this feature changes and that must be rewritten, not only added beside:
  - §4.1: the essential mark as a new optional field of the task (D8).
  - §5.8: a second cause of pause, the mode, independent of `pausada` (D3, D21-D23, D32); «Only recurring tasks can be paused» still holds (non-essential one-off tasks are hidden, not paused, D11); turning the mode off is a **Reanudar** of each non-essential recurring task not paused by hand (D21, D34).
  - §5.9: «A paused task cannot be postponed» also covers the pause by the mode (D31).
  - §6 Navigation / §6.1: the ⋮ button in the header of Pendientes with its menu (D5, D15), the «Modo mínimo» line (D6, D16, D26), which rows are in view with the mode on (D10, D11, D24) and the star of the row (D17, D30); **Mostrar pausadas** and **Mostrar completadas** with the mode on (D11, D24).
  - §6.2: the **Esencial** check in **Tarea** (D27, D33), counted for **Unsaved changes**; «Pausada por el modo mínimo» and the actions it hides (D31, D32); **Panel presentation**, order of the Tarea section.
  - §6.3: unchanged (D14).
  - §7: the essential mark in the list of independent fields of **Conflicts** (D18); the mode as synced user data, outside **Local preferences** (D34).
