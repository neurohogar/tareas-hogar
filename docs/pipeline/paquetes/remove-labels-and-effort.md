# Package: remove-labels-and-effort

Labels and the effort level leave the project. Tasks no longer have labels or an effort estimate: the row shows no label chips and no effort level, Pendientes has no label filter and no «Solo rápidas» button, the panel has no Etiquetas field and no Esfuerzo selector, and the Etiquetas screen and its tab disappear. Nothing replaces them. Deleting the production data (the labels collection and the label and effort fields of each task) is a separate, later step (D2), not part of this feature.

## Decisions

- D1 (2026-11-16, user, via orchestrator): labels (etiquetas) and the effort level (esfuerzo) are removed from the project entirely.
- D2 (2026-11-16, user, via orchestrator): the production data is deleted too (the labels collection and the label and effort fields of each task). That is an irreversible data migration that the orchestrator runs separately, only after this feature is deployed and with the user's explicit confirmation of the exact script. It is NOT part of this feature's code.
- D3 (2026-11-16, analyst, what disappears): everything that exists only for labels or effort goes, with no replacement: the `etiquetas` and `esfuerzo` fields of the task (§4.1); the Label entity with its palette, name rules, creation, color, order, rename, recolor and delete (§4.3); the label chips and the effort level of the row, the label filter with its chips and its empty text «No hay tareas con esta etiqueta», and the «Solo rápidas» button with its empty text «No hay tareas rápidas» (§6.1); the Etiquetas field (chips, suggestions, «Crear "x"», name errors) and the Esfuerzo selector of the panel (§6.2); the Etiquetas screen (§6.4). Because D1 removes both concepts entirely, and none of these parts has a meaning without them.
- D4 (2026-11-16, analyst, no other rule depended on them): the state rules (§5), the urgency order and its tie-breaks (§6.1), the date texts, «Última vez», History, the undo notice and the copied text never used labels or effort, so they do not change. Rules that only *mention* them lose the mention and keep everything else: «any effort» in **First step**, **Steps** and **Minimal version** (§4.1) disappears; «It does not change the status (§5), the order of the list, the filters or **Solo rápidas**» becomes «It does not change the status (§5) or the order of the list» (same for **Steps**, **No other effects**, and **Minimal version**); «An annotation does not store the active filters, the panel tab or mood scales» (§4.5) loses «the active filters». Because after D3 there are no filters left in Pendientes («Completadas» and «Pausadas» are checks of their own, and they are unchanged).
- D5 (2026-11-16, analyst, Pendientes): the top of Pendientes keeps only the «Completadas» and «Pausadas» checks, as today. **Mostrar completadas** and **Mostrar pausadas** lose the sentence «The label filter also applies to the completed / paused ones». There is no new empty-list text: with nothing to show, Pendientes behaves as it does today without a filter. Because the two empty texts belonged to the removed filters.
- D6 (2026-11-16, analyst, row texts that compared with effort): the rules that describe a row text «in the same size and secondary text color as the effort and the schedule» (step line and «Tocaba …», §6.1) say «as the schedule». Because the effort level no longer exists and the schedule text keeps the same secondary style, so the visible result does not change.
- D7 (2026-11-16, analyst, navigation): the tab bar has three tabs, in this order: **Pendientes** (`/`), **Historial** (`/historial`) and **Anotaciones** (`/anotaciones`). Because removing the Etiquetas screen (D3) removes its tab and keeps the order of the others.
- D8 (2026-11-16, analyst, by coherence, the old `/etiquetas` address; the orchestrator tells the user): opening `/etiquetas` (a bookmark, the browser history, or reloading a tab that was there when the new version arrived) opens Pendientes, replacing that history entry, with no notice. Because Pendientes is the main screen (§6.1) and a page with no content would be visual noise (§1); replacing the entry keeps **Atrás** from going back to it.
- D9 (2026-11-16, analyst, panel): the **Tarea** section keeps, in order: «Pausada», «Pospuesta hasta …» and **Última vez**; the title with its emoji; the first step and more steps; the minimal version; the note. In §6.2 the field list starts «Title, emoji and note», and the Esfuerzo and Etiquetas bullets go. The only error of **Tarea** is the title's; errors of **Cuándo** do not change. Because the two removed fields were the last ones of that section and the only other source of errors in **Tarea**.
